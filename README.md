
❤️ WishList App
WishList App is a Kotlin-based Android application that allows users to maintain a personal collection of items they would like to purchase or keep track of. The app uses Room Database as a local persistence layer, ensuring wishlist data remains available even after the application is closed or restarted.

The project demonstrates how to implement local database management and CRUD operations in Android using Kotlin. Users can add new wishlist items, view saved items, update existing information, and remove items they no longer need.

✨ Features
* ❤️ Add Wishlist Items – Add new items to your wishlist.
* 👀 View Wishlist – Display all saved wishlist items.
* ✏️ Edit Items – Update existing wishlist information.
* 🗑️ Delete Items – Remove items from the wishlist.
* 💾 Local Data Persistence – Store wishlist data locally using Room.
* 🗃️ Room Database – Manage structured local application data.
* 🔄 CRUD Operations – Complete Create, Read, Update, and Delete functionality.
* ⚡ Offline Support – Access saved wishlist data without an internet connection.
* 📱 Simple Android UI – Provide an easy-to-use wishlist management experience.

🎯 Project Purpose
The project was created to demonstrate practical local database implementation in Android using Kotlin and Room. It provides hands-on experience with database entities, DAO operations, CRUD functionality, data persistence, and separating the UI layer from database operations.
